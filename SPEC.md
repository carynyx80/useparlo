# Parlo — Attention Perps on BNB Chain (shared build spec)

Brand: **Parlo** (useparlo.xyz). Trade hype, not coins: go long/short with leverage on how much
attention a coin, trend or influencer gets on crypto social. Positions are private (hidden side,
leverage and owner) via ZK.

Monorepo layout (root = this folder):
```
contracts/   Foundry. Solidity ^0.8.24. forge-std already in lib/. PoseidonT3 at src/lib/PoseidonT3.sol
circuits/    Circom 2 + snarkjs (installed in circuits/node_modules: circom2, snarkjs, circomlib, circomlibjs)
server/      Node 22 + TypeScript backend (indexer + oracle reporter + relayer). Deployed on Railway.
web/         Vite + React + TS frontend. Deployed on Vercel at useparlo.xyz.
```

## Constants
- Chain: BNB Smart Chain mainnet, chainId 56. Testnet 97 supported via env.
- Collateral: BSC USDT `0x55d398326f99059fF775485246999027B3197955` (18 decimals).
- Company wallet (owner, treasury, fee recipient): `0xB34296465F18F55003100e925aBc70656E224035`
- Field p = 21888242871839275222246405745257275088548364400416034343698204186575808495617
- Merkle trees: depth 20, PoseidonT3 hashing, zero leaf = 0, zeros[i+1] = H(zeros[i], zeros[i]),
  root history of 30 roots. Two trees: `noteTree` (balance notes) and `positionTree`.
- Index values are uint scaled by 1e4 (attention score 100.0 = 1_000_000).
- Epoch length: `EPOCH_LENGTH` seconds (constructor arg, default 300). epoch = block.timestamp / EPOCH_LENGTH.
- Position window W = 16 epochs. Max leverage 20. Profit cap: payout ≤ 10 × margin.
  Fee: 10 bps of notional on open + 10 bps on close, deducted inside the close circuit payout.
- Markets: small integer ids 1..N (uint). Initial: 1 `$BNB`, 2 `$PEPE`, 3 `#AIAgents`, 4 `#Memecoins`,
  5 `@cz_binance`, 6 `#RWA`.

## Cryptography (Poseidon from circomlib; on-chain PoseidonT3 only for tree hashing)
- privKey: field element. Frontend derives it as keccak256(walletSignature("Parlo shielded account v1")) mod p.
- pubKey = Poseidon(privKey)                                   (1 input)
- Balance note commitment = Poseidon(amount, pubKey, blinding)  (3)
- Balance note nullifier  = Poseidon(commitment, privKey)       (2)
- Position commitment = Poseidon(marketId, isLong, margin, leverage, entryEpoch, pubKey, blinding) (7)
- Position nullifier  = Poseidon(positionCommitment, privKey)   (2)
- All amounts range-checked to 128 bits in circuits.

## Circuits (Groth16, snarkjs format). Public inputs IN THIS EXACT ORDER.
Verifier contracts are generated by `snarkjs zkey export solidityverifier` and renamed:
`contracts/src/verifiers/TransactVerifier.sol` (contract `TransactVerifier`), `OpenVerifier`, `CloseVerifier`.
Each exposes `verifyProof(uint[2] _pA, uint[2][2] _pB, uint[2] _pC, uint[N] _pubSignals) returns (bool)`.

1. **transact** (2-in / 2-out join-split; deposit, withdraw, self-transfer) — N = 7
   `[root, publicAmount, extDataHash, inNullifier0, inNullifier1, outCommitment0, outCommitment1]`
   - sum(inAmounts) + publicAmount == sum(outAmounts) (mod p). Input with amount 0 skips the Merkle check.
   - publicAmount = (extAmount - fee) mod p, where extAmount > 0 is a deposit, < 0 a withdrawal.
   - extDataHash = uint256(keccak256(abi.encode(recipient, extAmount(int256), relayer, fee, encOut0(bytes), encOut1(bytes)))) % p
2. **open** — N = 7
   `[root, inNullifier, changeCommitment, positionCommitment, marketId, margin, epoch]`
   - Spends one balance note (amount A) from noteTree; change note amount = A - margin; position note with
     given marketId, margin, entryEpoch = epoch, private isLong ∈ {0,1}, private leverage ∈ [1,20]. Same pubKey.
3. **close** — N = 56
   `[positionRoot, positionNullifier, outCommitment, marketId, margin, entryEpoch, closeOffset, payout,
     closes[0..15], lows[0..15], highs[0..15]]`
   - closes/lows/highs are the oracle's finalized values for epochs entryEpoch .. entryEpoch+15
     (contract fills them from storage; unfinalized slots passed as 0 and must have index > closeOffset).
   - 1 ≤ closeOffset ≤ 15. entry = closes[0], exit = closes[closeOffset].
   - notional = margin × leverage. liqPrice: long knocked out if any lows[1..closeOffset] ≤ entry × (1 − 0.9/leverage);
     short knocked out if any highs[1..closeOffset] ≥ entry × (1 + 0.9/leverage).
   - pnl = notional × (exit − entry) / entry (sign flipped for short); fee = notional × 20 / 10000.
   - payout = knockedOut ? 0 : clamp(margin + pnl − fee, 0, 10 × margin).
   - outCommitment = Poseidon(payout, pubKey, blinding') (new balance note owned by same key).

## Contracts (contracts/src)
- `AttentionOracle.sol` — owner + authorized reporters. `push(uint marketId, uint value)` updates current
  epoch's close/low/high; rejects moves > 20% vs previous value. `getEpoch(marketId, epoch) → (close, low, high, finalized)`
  where finalized = epoch < currentEpoch && close != 0. `addMarket(id, string symbol)`. Events for indexing.
- `LiquidityVault.sol` — ERC20 shares "Parlo LP" (PLP) over USDT; deposit/withdraw; only the pool can
  `receiveMargin` / `payOut`. Tracks reserved liability per entry epoch (margin×9), requires
  activeReserve ≤ 50% of assets on open; buckets expire after entryEpoch + W + 2.
  Half of fees → treasury (company wallet).
- `ParloPool.sol` — holds trader USDT. Two incremental Merkle trees (MerkleTreeWithHistory using PoseidonT3).
  `transact(proof, Ext ext)`, `openPosition(proof, pub)`, `closePosition(proof, pub)`; nullifier sets;
  emits `NewNote(commitment, index, encryptedOutput)` / `NewPosition(commitment, index, encryptedOutput)` /
  `NullifierSpent`. Open moves margin USDT to vault; close pulls payout from vault into the pool and inserts
  outCommitment. Close must happen before epoch entryEpoch + W + 2. Relayer fee paid from transact only.
  Owner can pause; deposit cap per tx and TVL cap (guarded launch).
- `script/Deploy.s.sol` — deploys everything with owner/treasury = company wallet, reads USDT address and
  EPOCH_LENGTH from env, writes `deployments/<chainId>.json`.
- Tests use mock verifiers (always true) plus a mock USDT, and an integration test using real verifiers
  if fixtures exist in `contracts/test/fixtures/`.

## Backend (server/) — env-driven, everything optional except PORT
- Indexer: every 60s per market compute attention score from sources: Reddit search JSON, CoinGecko
  trending, Farcaster (only if NEYNAR_API_KEY), X (only if X_BEARER_TOKEN), plus deterministic simulator
  fallback. Score = EMA of weighted mentions/engagement/unique authors, scaled 1e4.
- REST: `GET /health`, `GET /markets`, `GET /markets/:id/history?range=24h`, `GET /pool/notes?from=`,
  `GET /pool/positions?from=` (leaves + encrypted outputs from chain events), `POST /relay/transact|open|close`.
- Reporter: if REPORTER_PRIVATE_KEY + ORACLE_ADDRESS set, push scores on-chain each epoch.
- Relayer: if RELAYER_PRIVATE_KEY + POOL_ADDRESS set, submit proofs (validates them with snarkjs first).
- CORS for https://useparlo.xyz and localhost. Dockerfile + railway.json.

## Frontend (web/)
- Framer-style marketing site at `/` + trading app at `/app`. Dark, premium, smooth motion (framer-motion).
- Wallet: wagmi v2 + viem + RainbowKit, BSC mainnet (and testnet if VITE_CHAIN=97).
- Env: VITE_API_URL, VITE_WC_PROJECT_ID, VITE_POOL_ADDRESS, VITE_ORACLE_ADDRESS, VITE_VAULT_ADDRESS, VITE_CHAIN.
- Private trading: derive shielded key from signature, scan notes, in-browser snarkjs proving with
  `/zk/{transact,open,close}.wasm|.zkey` from web/public/zk/.
